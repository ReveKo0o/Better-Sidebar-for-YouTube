# SideTube | Better Sidebar for YouTube

SideTube is a lightweight and modern browser extension that redesigns the YouTube interface into a floating, rounded sidebar layout, accompanied by a repositioned search bar, a transparent category filter bar, and a built-in customization studio.

# Features

* **Floating Glass Sidebar**: Replaces the default rigid side navigation with a modern, rounded, floating panel featuring a subtle border and shadow.

* **Background Customization Studio**: Allows users to upload their own images, adjust blur and opacity live, and download a customized background file tailored for the sidebar.

# Installation

1. Download or clone this repository to your local machine.
2. Open Google Chrome and navigate to chrome://extensions/.
3. Enable Developer mode using the toggle switch located in the top-right corner.
4. Click the Load unpacked button in the top-left corner.
5. Select the folder containing the extension files.

# How to Customize Sidebar Background

1. Click on the SideTube extension icon in your browser toolbar to open the quick panel.
2. Click the customization button to open the web studio.
3. Upload your preferred background image using the file selector.
4. Adjust the opacity and blur sliders to achieve the desired look with live preview.
5. Click the download button to save the generated `sidebar-bg.png` file.
6. Replace the existing `sidebar-bg.png` file inside your local extension folder with the newly downloaded file.
7. Go back to `chrome://extensions/` and click the reload icon on the SideTube extension card to apply changes.
